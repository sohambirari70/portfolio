# Soham Birari — Personal Portfolio

A modern, interactive personal portfolio built with **React**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Features
- **Interactive Hero Section** with animated role ticker and responsive particle network canvas
- **Dark / Light Theme Toggle** persisted in `localStorage`
- **About Me** section with editable portrait (URL or local upload)
- **Skills & Stack** grouped into Programming, Core Concepts, and Tools with status filtering
- **Projects Showcase** with category filters, clearly marked editable sample placeholders, and an accessible detail modal
- **Education, Journey & Currently Learning** sections tailored for a first-year B.Tech CSE (AI & ML) student at Newton School of Technology, Pune
- **Local Portfolio Editor** (`Edit Portfolio` button) to customize profile, skills, projects, journey milestones, and links live, with JSON export/import and reset
- **Contact Form** with client-side validation and direct email (`mailto:`) / copy-to-clipboard actions

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
